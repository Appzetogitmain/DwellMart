# 🏷️ Badge Component

The `<Badge>` component is a pill tag used for status indicators, vendor verification, sale highlights, and flash deals across DwellMart.

## Usage Example

```jsx
import { Badge } from '@/shared/components/ui';

<Badge variant="verified">Verified Seller</Badge>
<Badge variant="hot">Hot Deal</Badge>
<Badge variant="gold">20% OFF</Badge>
```
