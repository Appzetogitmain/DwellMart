# 🧱 DwellMart Primitive UI Component Library (Phase 2A)

This library contains the 6 core primitive foundation components:
1. **`<Button>`**: Polymorphic forwardRef button system (`primary`, `secondary`, `outline`, `danger`, `ghost`).
2. **`<Input>`**: ForwardRef primitive input with built-in password eye toggle, search clear, icons, and label binding.
3. **`<Select>`**: ForwardRef custom select with native mobile fallback and custom chevron.
4. **`<TextArea>`**: Multi-line text input with real-time character counter.
5. **`<Badge>`**: Status & brand tag pills (`verified`, `new`, `hot`, `trending`, `gold`, `success`, `warning`, `error`, `info`).
6. **`<Card>`**: Polymorphic surface card with compound `<Card.Header>`, `<Card.Body>`, `<Card.Footer>`, `<Card.Actions>`.

All components consume Theme Engine tokens, CSS custom properties, and `data-component` attributes.
